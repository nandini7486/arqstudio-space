ArQ Studio - Coming Soon page
Files: index.html, logo.png, favicon.png, og-image.png (keep all in the same folder).

GitHub Pages:
1. Create a new public repository on GitHub.
2. Upload these 4 files to the root of the repository (index.html must be at the top level).
3. Settings > Pages > Source: "Deploy from a branch" > Branch: main, folder: / (root) > Save.
4. In Settings > Pages > Custom domain, enter your domain and follow the DNS instructions shown there.
5. Open index.html and replace YOUR-DOMAIN.com in the og:image line with your real domain.
